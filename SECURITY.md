# Security / Sécurité

Please do not disclose exploitable vulnerabilities or personal network data in public issues. Use GitHub's **Security → Report a vulnerability** on this repository when available. If private reporting is unavailable, open a minimal issue requesting a private contact method without exploit details or sensitive data.

Atlas is an experimental observation tool, not a firewall or a guarantee that a connection is safe. Only the latest release is maintained. Report the affected version and a minimal reproduction using synthetic data. Do not send your connection database.

Ne publiez pas de vulnérabilité exploitable ni de données réseau personnelles dans une issue publique. Utilisez **Security → Report a vulnerability** si disponible. À défaut, demandez un canal privé dans une issue minimale sans détail d'exploitation. Seule la dernière version est maintenue.

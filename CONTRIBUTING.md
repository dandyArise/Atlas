# Contributing / Contribuer

Bug reports and contributions in English or French are welcome. Explain the expected behavior, actual behavior, Windows version and Atlas version. Replace real addresses with documentation ranges such as `203.0.113.0/24` and paths with placeholders. Do not upload your database or real traffic screenshots.

Build and run the verification commands in the README before submitting a pull request. Keep fixes focused and add meaningful tests for changed collection, persistence or matching behavior. UDP verification needs a real elevated Windows session; label untested assumptions clearly. Never call UDP/443 confirmed QUIC without protocol evidence.

Contributions are provided under the project's MIT license. Preserve third-party notices. Dependency updates must include the lockfile. Do not commit binaries, credentials, personal paths or captured traffic.

Les contributions et rapports en français sont bienvenus. Décrivez le problème et les étapes de reproduction avec des données fictives. Exécutez les contrôles du README et indiquez clairement ce qui n'a pas pu être testé. Les contributions suivent la licence MIT du projet.
